# Все задания

В этой папке собраны три проекта на PHP.

## 1. Глухая бабушка (`babka/`)

Консольная программа. Версия `v1` отвечает на крик и прощается по команде `ПОКА!`, версия `v2` требует три команды `ПОКА!` подряд.

Запуск:

```
php v1/babka.php
php v2/babka.php
```

## 2. CAPTCHA (`captcha/`)

Веб-программа: генерирует картинку с случайной строкой поверх `noise.jpg`, хранит код в сессии и проверяет ввод. Есть счётчик из трёх попыток и обновление картинки.

Запуск:

```
php -S 127.0.0.1:8000 -t captcha
```

## 3. Интернет-магазин (`bookshop/`)

Каталог книг, корзина в cookie, заказы, админка, хранимые процедуры MySQL. Логин админки: `admin`, пароль `admin`.

Запуск:

```
php -S 127.0.0.1:8000 -t bookshop
```

Подробности в `bookshop/README.md`. База данных создаётся из `bookshop/core/eshop.sql`.
